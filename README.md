# Alisher Ahmed — Portfolio

Static single-page site (HTML/CSS/JS). No build step.

## Deploy to Vercel
**GitHub (recommended)**
1. Push this folder to the `Ali1524/My-new-portfolio` GitHub repository.
2. In Vercel, choose **Add New → Project** and import `Ali1524/My-new-portfolio`.
3. Set Framework Preset to **Other**. Leave Build Command and Output Directory empty.
4. Click **Deploy**. Vercel serves `index.html` from the project root.

**Vercel CLI**
```
npx vercel --prod
```
